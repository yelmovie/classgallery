# CLASS GALLERY 95점권 제출 준비 자료

## 1. 배포 전 관리자 보안 설정

이 프로젝트는 정적 웹앱이므로 서버 기반 계정 보안이 아니다. 대신 제출/시연용 관리자 화면에는 평문 비밀번호를 코드에 넣지 않고 SHA-256 해시로 검증한다.

### 권장 설정

1. 관리자 비밀번호를 정한다.
2. 아래 명령으로 해시를 만든다.

```bash
npm run admin:hash -- <admin-password>
```

3. Vercel 또는 로컬 `.env`에 아래 값을 설정한다.

```bash
VITE_CLASSGALLERY_ADMIN_HASH=<generated-hash>
```

4. 다시 빌드한다.

```bash
npm run build
```

### 비고

- 해시가 설정되지 않은 경우 `/admin` 첫 접속 때 해당 기기에서 관리자 비밀번호를 설정한다.
- 완전한 계정 보안이 필요한 공개 서비스 단계에서는 서버 인증 또는 학교 계정 OAuth가 필요하다.

## 2. 5분 시연 영상 구성안

### 0:00-0:30 문제 제기

- 교사가 학생 작품을 모아 전시하기 어렵다.
- 학습지가 수업 후 사진첩에 흩어지고, 발표와 감상이 분리된다.
- CLASS GALLERY는 학습지 작성부터 전시, 저장, 공유까지 한 흐름으로 묶는다.

### 0:30-1:20 주제팩 선택

- `/packs`에서 독도, 안전, 환경, 다문화, 학교폭력 예방, 정보윤리 등 계기교육 주제를 보여준다.
- 주제마다 학습지, 배경, 샘플 작품이 함께 제공됨을 강조한다.

### 1:20-2:20 작품 수집

- `/control`에서 샘플 작품 채우기 또는 실제 학습지 사진 업로드를 시연한다.
- 가능하면 카메라 촬영도 짧게 보여준다.
- 실패 대비: 카메라 권한이 막히면 파일 업로드로 대체 가능하다고 설명한다.

### 2:20-3:30 전시 화면

- `/display`에서 작품이 배경 위에 움직이는 전시 화면을 보여준다.
- 속도 조절, 정지, 배경 변경, 집중 감상 기능을 보여준다.
- 새 창 전시는 교실 TV나 빔프로젝터에 띄우는 용도라고 설명한다.

### 3:30-4:20 결과 저장과 공유

- 갤러리 저장 버튼으로 PNG를 저장한다.
- 메일 기능은 자동 발송이 아니라 이미지 저장 후 메일 작성창을 여는 방식임을 정확히 말한다.
- QR 또는 링크 공유를 보여주고, QR이 안 뜨면 링크 복사를 쓰면 된다고 안내한다.

### 4:20-5:00 확장성

- `/admin`에서 교사가 직접 주제를 추가할 수 있음을 보여준다.
- 배경, 샘플, 학습지를 올리면 새 주제팩처럼 수업에 쓸 수 있다는 점을 마무리 메시지로 삼는다.

## 3. 교사용 1장 매뉴얼

### 수업 전

- 사용할 주제팩을 고른다.
- 학습지를 인쇄한다.
- 교실 TV/빔프로젝터에서 `/display`를 열 준비를 한다.
- 배포 환경에서는 관리자 해시를 설정해 둔다.

### 수업 중

- 학생이 학습지에 색칠하거나 약속 문장을 작성한다.
- 교사는 `/control`에서 사진 파일을 올리거나 카메라로 촬영한다.
- 작품이 잘 잘렸는지 오른쪽 미리보기를 확인한다.
- 전시 시작 버튼을 눌러 교실 화면에 띄운다.
- 속도와 배경을 조절하며 감상 활동을 진행한다.

### 수업 후

- 갤러리 이미지를 PNG로 저장한다.
- 학급 공유가 필요하면 메일 작성창에 저장된 이미지를 첨부한다.
- 다음 수업 주제가 필요하면 관리자 화면에서 새 주제를 만든다.

## 4. 학생 결과물 예시 설명

제출 자료에는 실제 학생 개인정보 없이 아래 형태의 예시를 넣는다.

- 독도교육: 독도 바다 배경 위에 학생이 색칠한 바다 생물 캐릭터가 움직이는 장면
- 학교안전교육: 복도, 과학실, 운동장 배경 위에 안전 약속 캐릭터가 전시되는 장면
- 환경교육: 숲/바다 배경 위에 지구를 지키는 약속 캐릭터가 떠다니는 장면
- 정보윤리교육: 개인정보 보호, 바른 댓글, 가짜뉴스 확인 약속 캐릭터가 전시되는 장면

## 5. 브라우저/배포 체크리스트

### 필수 테스트

- Chrome 최신 버전: 파일 업로드, 전시 화면, PNG 저장, 관리자 로그인
- Edge 최신 버전: 새 창 전시, 팝업 차단 안내, QR/링크 공유
- iPad 또는 Android 태블릿: 카메라 권한, 촬영, 파일 업로드 대체 흐름
- 학교망 또는 제한망: QR 이미지 실패 시 링크 복사 안내

### 실패 시 대체 흐름

- 카메라 권한 실패: 파일 업로드로 진행
- 팝업 차단: 현재 탭 전시 화면 사용 또는 팝업 허용
- 메일창 차단: 다운로드 폴더의 PNG를 직접 첨부
- QR 이미지 실패: 링크 복사로 공유
- 자동 배경 제거 실패: 사진을 밝은 곳에서 다시 찍거나 학습지 영역이 크게 나오도록 재촬영
